# Raw Dataset

The raw datasets used in this project are from the Brazilian E-Commerce Public Dataset by Olist.

The original CSV files are excluded from this GitHub repository to keep the repository lightweight.

Dataset source: [Brazilian E-Commerce Public Dataset by Olist – Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Download the dataset and place all CSV files in this folder before running the SQL scripts.

Expected files:
- olist_customers_dataset.csv
- olist_geolocation_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv
- olist_orders_dataset.csv
- olist_products_dataset.csv
- olist_sellers_dataset.csv
- product_category_name_translation.csv
